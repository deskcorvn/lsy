# Using GiftyTech Art Direction

Use this design system when working on GiftyID/GiftyTech surfaces:

- `projects/giftyid`
- ECard landing/profile.
- Chợ Z, Mua chung công đoàn, QR nhận hàng.
- Mini App thương hiệu riêng.
- Website 5 trụ cột.
- Gifty capability/profile pages.

## Start Here

1. Read `DESIGN.md`.
2. Pick one page lane:
   - `command-hero`
   - `product-stage`
   - `editorial-proof`
   - `data-story`
   - `premium-profile`
3. Preserve existing brand palette unless the task explicitly asks for a rebrand.
4. Replace repeated card grids with one more specific visual system when possible.
5. Use real screenshots/photos/QR before decorative graphics.

## Minimum Change Upgrade

For a quick pass on an existing page:

- Reduce repeated eyebrows.
- Tighten typography scale and line length.
- Replace one card grid with a flow/proof/device section.
- Add source captions to real proof images.
- Check floating buttons do not cover product visuals.
- Add reduced-motion-safe microinteraction to the most important action only.
